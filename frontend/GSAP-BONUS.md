# GSAP Club / Bonus package

This folder documents the GreenSock Club bonus package used by the Santamar front-end.

- Archive: repo-root `gsap-bonus.tgz`
- Installed as the `gsap` npm dependency via `file:../gsap-bonus.tgz`
- Animation helpers: `frontend/src/lib/gsap.ts` (`SplitText`, `ScrollTrigger`, fade/reveal utilities)

Do not replace with the public npm `gsap` package if you need Club plugins (`SplitText`, `ScrollSmoother`, `DrawSVGPlugin`, etc.).
